## 2. Reproducción del trabajo

Para reproducir la práctica, es necesario disponer de PostgreSQL y pgAdmin instalados.

### Crear la base de datos

1. Abrir **pgAdmin**.
2. Crear una nueva base de datos para la práctica, por ejemplo:

```sql
CREATE DATABASE northwind;
```

3. Conectarse a la base de datos creada desde pgAdmin.

### Cargar el script

Una vez creada y seleccionada la base de datos:

1. Abrir **Query Tool** en pgAdmin.
2. Cargar el script SQL proporcionado para crear la estructura y los datos de la base de datos.
3. Ejecutar el script completo.
4. Comprobar que las tablas de **Northwind Traders** se han creado correctamente y contienen los datos necesarios para realizar las consultas.
